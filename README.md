# SQL Practice & Database Management

This repository contains my SQL learning journey, database assignments, and practical query-solving exercises. It covers basic SQL commands, real-world database operations, and assignment-based practice using MySQL.

## 📚 Repository Contents

### 1. Basic DQL Commands

Practicing Data Query Language (DQL) commands to retrieve and analyze data from databases.

**Topics Covered:**
- `SELECT` – Retrieve data from a table.
- `DISTINCT` – Retrieve unique records.
- `WHERE` – Filter records based on conditions.
- `AND`, `OR`, `NOT` – Apply multiple conditions.
- `BETWEEN` – Retrieve values within a range.
- `IN` – Match values from a given list.
- `LIKE` – Search for a specific pattern.
- `IS NULL` – Check for NULL values.
- `ORDER BY` – Sort records in ascending or descending order.
- `LIMIT` – Restrict the number of returned records.
- Aggregate Functions:
  - `COUNT()`
  - `SUM()`
  - `AVG()`
  - `MIN()`
  - `MAX()`
- `GROUP BY` – Group records based on columns.
- `HAVING` – Filter grouped records.
