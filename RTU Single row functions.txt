1.	Write a query which will display username in upper case, role first letter capitalized and all other letters lower case and length of the username.

//Convert upper case
mysql> select UPPER(ename) from emp;
+--------------+
| UPPER(ename) |
+--------------+
| SHREYA       |
| MAHESH       |
| YAMINI       |
| SURESH       |
+--------------+
4 rows in set (0.00 sec)

//Role first letter capitalized 
mysql> select CONCAT(UPPER(lEFT(ename,1)),LOWER(substring(ename,2))) as titleName from emp;

| titleName |
+-----------+
| Shreya    |
| Mahesh    |
| Yamini    |
| Suresh    |
+-----------+

2.	Display number of sensors enabled and disabled. Sort on number of sensors

mysql> SELECT status, COUNT(*) AS total_sensors
    -> FROM sensors
    -> WHERE status IN ('ENABLED', 'DISABLED')
    -> GROUP BY status
    -> ORDER BY total_sensors ASC;
+----------+---------------+
| status   | total_sensors |
+----------+---------------+
| DISABLED |             3 |
| ENABLED  |             8 |
+----------+---------------+
2 rows in set (0.00 sec)

5.	Display how many sensors are controlled by each user. Exclude users who are controlling less than 3 sensors and also restrict users with id “U503”. Sort on user_id.

mysql> SELECT RTU_ID, COUNT(*) AS total_sensors
    -> FROM sensors
    -> WHERE RTU_ID <> 'R103'
    -> GROUP BY RTU_ID
    -> HAVING COUNT(*) >= 3
    -> ORDER BY RTU_ID ASC;
+--------+---------------+
| RTU_ID | total_sensors |
+--------+---------------+
| R101   |             3 |
| R102   |             4 |
+--------+---------------+
2 rows in set (0.00 sec)
